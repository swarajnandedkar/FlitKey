### 3. Founder technical note — schedule 6–7 hours after launch

Linux is not one input environment.

X11 allows typed triggers and global hotkeys. Native Wayland restricts global input simulation, so FlitKey uses Quick Insert + clipboard paste.

An honest fallback beats automation that fails silently.

https://www.producthunt.com/products/flitkey-text-expander?launch=flitkey-text-expander
